Cargar descuento

Registrá una oferta de una droguería: puede aplicar a un producto puntual, a una droga, a un laboratorio, o de forma general.

Todas las filas del archivo se cargan como descuentos para productos puntuales de una sola droguería (la indicás una vez abajo, no hace falta repetirla en cada fila). Columnas del excel: nombre, codigo de barras, troquel, descuento y cantidad mínima (opcional) — el orden no importa. El producto se busca primero por código de barras o troquel exacto, y si no los tenés, por nombre parecido. Lo que no se encuentre no se inventa: se junta en un reporte para que lo cargues a mano después en "Productos y catálogos".
